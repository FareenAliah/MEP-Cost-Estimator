# MEP-Cost-Estimator
In building services and construction engineering, early-stage cost estimation is often manual, slow, and prone to human error when cross-checking historical data against architectural drawings. I wanted to conceptualize an automated system that bridges spatial data extraction from PDFs with structured financial modelling. 
The estimator.py only applicable for new building only for cost estimator based on previous award with ability to extract data from pdf of CAD file to estimate per area from architect drawing and certain items no of proposed lift as per concept drawing. Although at concept drawing, engineer unable to give exact number of lifts required unless it being calculated by lift analysis, by referring to past project based on area, height, type of building, room or unit number is applicable, this estimator able to propose first estimated lift number.
For renovation project, the coding shall be different from new building type as user required to different building based on year of used and equipment that required replacement or maintenance. Although the cost will be estimated by area, some input shall be given to estimate cost of replacement big equipment such as pump, sprinkler head, lighting point, FCU and others. Separate coding programme will be created to achieve this. User also can apply same method by upload the pdf architecture drawing and past previous awarded cost by catogories.
The exact estimate cost by drawing is the last project for this automation system whereby, user can upload full MEP drawing that AI can read the estimate pipe length, wiring and other whether through pdf or BIM Model. Although in Revit and CAD have this system, but the ability to produce cost reflected by previous project with inflation or provide new total cost automated by country still lack in construction industry or BIM industry. 
With this new automation system, not only assist engineer in construction industry but also other different engineering industry. The ability AI automation system to cooperate with multiply modelling software is what practical engineer sought for.
